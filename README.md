# tv-setup

Одна команда настраивает Android TV по сети: быстрый лаунчер, Happ, AirPlay для iPhone.

## Что нужно

1. Телевизор на Android TV 8 или новее и ноутбук в одной сети (один роутер).
2. На телевизоре включена отладка по сети:
   - Настройки → Об устройстве → 7 раз нажать на «Сборка» (появятся «Для разработчиков»);
   - Настройки → Для разработчиков → включить «Отладка по USB» и «Отладка по сети» (или «Отладка по ADB»).
3. IP-адрес телевизора: Настройки → Сеть → ваша сеть → IP-адрес (например, `192.168.0.143`).

## Запуск

**Windows** — PowerShell (Пуск → PowerShell):

```powershell
irm https://raw.githubusercontent.com/Mag1c3R/tv-setup/main/install.ps1 | iex
```

**Mac или Linux** — Терминал:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Mag1c3R/tv-setup/main/install.sh)
```

Команда спросит IP телевизора. Когда на телевизоре появится «Разрешить отладку?» — нажмите «Разрешить» пультом.
Дальше она спросит город (для фона-неба), предложит отключить голосовой ассистент и Chromecast и в конце —
выключить отладку. Занимает 3–5 минут.

## Поставить любое приложение по ссылке (Windows)

```powershell
irm https://raw.githubusercontent.com/Mag1c3R/tv-setup/main/install-apk.ps1 | iex
```

Спросит IP телевизора, затем прямую ссылку на `.apk` (или путь к файлу на ноутбуке) и поставит его. Можно
вводить несколько ссылок подряд, пустой Enter — закончить. Ставьте только из источников, которым доверяете.

## Что ставится

| Что | Откуда |
|---|---|
| Лаунчер (главный экран): часы с днём недели и датой, док из 5 приложений, кнопка VPN, небо по времени суток, без рекламы и интернета | сборка из этого репозитория, выпуск [Releases](../../releases) |
| Happ (VPN) | официальный выпуск [Happ-proxy/happ-android](https://github.com/Happ-proxy/happ-android) |
| AirPlay-приёмник: «Повтор экрана» с iPhone, сам выходит на экран при подключении | [jqssun/android-airplay-server](https://github.com/jqssun/android-airplay-server) |
| Помощник AirPlay: закрывает приёмник, когда iPhone отключился | `airplay-autoclose/` в этом репозитории |

Каждый файл скачивается с GitHub, и его SHA-256 сверяется с тем, что публикует GitHub. Не совпало — установка
останавливается.

Ещё команда: делает лаунчер главным экраном (стандартный не отключается и не удаляется), сокращает анимации
системы вдвое, сохраняет на ноутбук бэкап списка приложений и настроек телевизора (`tv-backup-…` в папке
пользователя).

## После установки

- Кнопка **VPN** сверху открывает Happ: добавьте в нём свою подписку.
- **AirPlay**: на iPhone «Пункт управления» → «Повтор экрана» → «Android AirPlay».
- Держите **OK** на плитке приложения: переместить, поставить в док, удалить.
- Не оставляйте AirPlay-приёмник открытым на вкладке Settings: помощник видит отключение iPhone только на вкладке Overview.

## Откат

- Стандартный главный экран: «Домой» на пульте → выбрать прежний → «Всегда», или Настройки → Приложения →
  лаунчер → Удалить.
- Ассистент и Chromecast: Настройки → Приложения → Показать системные → включить.
- Анимации: Для разработчиков → три пункта «Анимация» → 1x.
